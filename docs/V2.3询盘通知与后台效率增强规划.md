## 四、后端接口变更

### 4.1 新增接口

| 接口 | 方法 | 说明 | 鉴权 |
|------|------|------|------|
| `/api/admin/inquiries/export` | GET | 导出询盘列表为 Excel | JWT |
| `/api/admin/inquiries/{id}/copy-info` | GET | 返回客户联系方式 JSON（供前端复制） | JWT |

### 4.2 修改接口

| 接口 | 变更 | 说明 |
|------|------|------|
| `GET /api/admin/inquiries` | 新增查询参数 | status、startDate、endDate、keyword |
| `GET /api/admin/dashboard/stats` | 新增字段 | pendingCount（待处理询盘数） |
| `POST /api/public/inquiries` | 新增逻辑 | 提交成功后触发邮件通知 |

### 4.3 邮件通知流程

```
客户提交询盘 → PublicController.saveInquiry()
  → inquiryService.create() / createWithItems()
  → 异步发送邮件通知管理员
  → 返回成功响应
```

邮件内容包含：客户姓名、公司、邮箱、电话、产品列表、留言。

## 六、邮件配置方式

### 方案 A：site_config 存储（推荐）

邮件配置存储在 `site_config` 表中，管理员在后台"站点配置"页面填写：

| key | 说明 | 示例 |
|-----|------|------|
| `smtp_host` | SMTP 服务器 | smtp.qq.com |
| `smtp_port` | SMTP 端口 | 465 |
| `smtp_user` | 发件人邮箱 | notice@example.com |
| `smtp_pass` | 邮箱密码/授权码 | xxxxxxxx |
| `notify_email` | 通知收件人 | admin@xinlianxin.com |

**优点：** 管理员可自行修改，无需重新部署
**缺点：** 密码存储在数据库（需加密）

### 方案 B：环境变量

邮件配置通过环境变量注入：

```bash
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=notice@example.com
SMTP_PASS=xxxxxxxx
NOTIFY_EMAIL=admin@xinlianxin.com
```

**优点：** 安全，不入库
**缺点：** 修改需重新部署

**推荐方案 A**，密码使用 AES 加密存储。

## 七、Excel 导出方案

### 技术选型

使用 Apache POI（已有 spring-boot-starter 间接依赖）或 EasyExcel（阿里巴巴开源库）。

推荐 **EasyExcel**：
- 轻量，内存占用低
- 支持注解映射
- 社区活跃

### 导出字段

| 列 | 字段 | 来源 |
|----|------|------|
| 1 | 询盘编号 | inquiry.id |
| 2 | 客户姓名 | inquiry.name |
| 3 | 公司 | inquiry.company |
| 4 | 邮箱 | inquiry.email |
| 5 | 电话 | inquiry.phone |
| 6 | 微信 | inquiry.wechat |
| 7 | WhatsApp | inquiry.whatsapp |
| 8 | 国家 | inquiry.country |
| 9 | 产品名称 | inquiry.productName 或 inquiry_item 汇总 |
| 10 | 数量 | inquiry.quantity 或 inquiry_item 汇总 |
| 11 | 规格 | inquiry.specification 或 inquiry_item 汇总 |
| 12 | 留言 | inquiry.message |
| 13 | 状态 | inquiry.status |
| 14 | 提交时间 | inquiry.createdAt |

### 导出范围

- 默认导出当前筛选结果
- 无筛选时导出全部（最多 1000 条，超出提示）
- 文件名格式：`询盘导出_YYYYMMDD_HHmmss.xlsx`

## 十、风险和回滚方案

### 风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 邮件服务器配置不当 | 通知无法送达 | 提供测试按钮，配置后可验证 |
| Excel 导出内存溢出 | 大数据量导出 OOM | 限制最大导出 1000 条，使用 EasyExcel 流式写入 |
| 邮件发送阻塞请求 | 接口响应变慢 | 使用 @Async 异步发送，不阻塞主流程 |
| EasyExcel 依赖冲突 | 构建失败 | 排查 POI 版本，必要时 shade 冲突类 |
| 筛选参数 SQL 注入 | 安全风险 | 使用 MyBatis Plus 参数化查询，不拼接 SQL |

### 回滚方案

| 场景 | 回滚方式 |
|------|----------|
| 邮件功能异常 | 关闭邮件通知开关（site_config），保留其他功能 |
| Excel 导出异常 | 移除导出按钮，后端接口保留但不暴露 |
| 筛选功能异常 | 回退 Inquiries.vue 筛选组件，后端接口兼容无参数调用 |
| 全部回滚 | revert V2.3 所有提交，数据库无新增表无需回滚迁移 |
