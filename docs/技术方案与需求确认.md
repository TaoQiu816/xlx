# 丝网工厂官网与销售系统 — V1 技术方案与需求确认

## 1. 项目信息

| 项目 | 内容 |
|------|------|
| 公司名称 | 鑫连鑫丝网厂 |
| 英文名称 | XINLIANXIN WIRE MESH FACTORY |

## 2. V1 范围

### 2.1 V1 做

- 中文前台展示网站（8 个页面）
- 中文后台管理系统
- 产品分类、产品、规格、图片、工厂图片、证书的增删改查
- 客户询盘提交与后台管理
- 文件上传（产品图、工厂图、证书、询盘附件）
- 移动端适配
- 数据字段预留中英文
- 数据库/代码结构预留订单、支付、客户注册扩展

### 2.2 V1 不做（明确排除）

- **在线支付**（支付宝、微信支付、PayPal、信用卡均不做）
- **购物车 / 询价车**
- **客户注册 / 客户中心**
- 多角色权限
- **多语言正式上线**（数据字段预留，但不提供语言切换）
- 自动报价
- AI 客服 / ERP 对接

## 9. 页面设计要求

- 主色：深蓝/藏青
- 辅助色：钢灰/浅灰
- 按钮色：蓝色或橙色
- 背景：白色/浅灰
- 风格：简洁、工业风、B2B、工厂感
- 不花哨、不做复杂动画、不用廉价模板
- 移动端按钮 ≥ 44px，表单大输入框
- 规格表手机端可横向滚动

## 10. 安全要求

- 后台接口 JWT 鉴权
- 密码加密存储（BCrypt，V1 暂用 MD5）
- 文件上传限制类型（图片/文档，禁止可执行文件）
- 文件上传限制大小（单文件 ≤ 10MB）
- 删除操作二次确认
- 表单基础校验
- CORS 跨域限制（通过环境变量配置允许来源）
- SQL 注入防护（MyBatis Plus 参数化查询）
- XSS 防护（Vue 模板默认转义）
- 错误信息不暴露堆栈（GlobalExceptionHandler 兜底）

## 11. CORS 跨域配置

### 11.1 配置方式

通过环境变量 `CORS_ORIGINS` 控制允许的来源域名：

```yaml
# application.yml
cors:
  allowed-origins: ${CORS_ORIGINS:http://localhost:3000,http://localhost:3001}
```

### 11.2 实现

**文件：** `xlx-gateway/.../WebMvcConfig.java`

```java
@Value("${cors.allowed-origins:http://localhost:3000,http://localhost:3001}")
private String allowedOrigins;

@Override
public void addCorsMappings(CorsRegistry registry) {
    String[] origins = allowedOrigins.split(",");
    registry.addMapping("/api/**")
            .allowedOriginPatterns(origins)
            .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
            .allowedHeaders("*")
            .allowCredentials(true)
            .maxAge(3600);
}
```

### 11.3 生产环境配置

```bash
export CORS_ORIGINS="https://xlxcn.cn,https://www.xlxcn.cn"
```

## 12. 错误处理策略

### 12.1 全局异常处理器

**文件：** `xlx-common/.../GlobalExceptionHandler.java`

| 异常类型 | HTTP 状态码 | 返回内容 |
|----------|-------------|----------|
| BusinessException | 400 | 业务错误信息 |
| MethodArgumentNotValidException | 400 | 字段校验错误 |
| BindException | 400 | 表单绑定错误 |
| MaxUploadSizeExceededException | 400 | "文件大小超过限制" |
| Exception（兜底） | 500 | "服务器内部错误" |

### 12.2 安全原则

- 未预期的异常只返回通用错误信息，不暴露堆栈
- 详细错误信息仅记录在服务端日志
- BusinessException 的 message 为业务友好提示，可返回前端

### 12.3 前端错误处理

- Axios 响应拦截器统一处理 HTTP 错误
- 401 自动跳转登录页
- 其他错误显示 ElMessage.error 提示
