# V1.3 SEO 优化规划

> 鑫连鑫丝网厂 B2B 官网 — SEO 基础建设
> 创建日期：2026-06-06
> 阶段定位：V1.2 UI 优化完成，提升搜索引擎可见性

---

## 一、阶段目标

1. 每个页面有独立的 title 和 meta description
2. 支持 Open Graph 社交分享标签
3. 提供 robots.txt 和 sitemap.xml
4. 关键页面有 JSON-LD 结构化数据
5. 后台可配置 SEO 相关字段

---

## 二、明确不做的功能

| 不做 | 原因 |
|------|------|
| SSR / SSG 预渲染 | SPA 场景下 ROI 不高，V2 考虑 |
| 多语言 hreflang 标签 | V2.1 国际化时一起做 |
| 自动 sitemap 生成 | 产品数量有限，手动维护即可 |
| SEO 分析仪表盘 | 非核心功能 |

---

## 三、技术方案

### 3.1 Head 管理

- 使用 `@unhead/vue` 提供 `useHead` 和 `useSeoMeta` 组合式函数
- 路由守卫设置 document.title 作为兜底
- 每个页面组件调用 `useSEO()` 设置专属 meta

### 3.2 页面 SEO 策略

| 页面 | title | description | 结构化数据 |
|------|-------|-------------|-----------|
| 首页 | 鑫连鑫丝网厂 | 工厂介绍+产品概述 | Organization + BreadcrumbList |
| 关于我们 | 关于我们 | 公司介绍 | BreadcrumbList |
| 产品中心 | 产品中心 | 产品分类概述 | BreadcrumbList |
| 产品详情 | 动态产品名 | 产品简介 | Product + BreadcrumbList |
| 工厂展示 | 工厂展示 | 生产实力介绍 | BreadcrumbList |
| 资质证书 | 资质证书 | 认证信息 | BreadcrumbList |
| 常见问题 | 常见问题 | FAQ 概述 | BreadcrumbList |
| 联系我们 | 联系我们 | 联系方式 | BreadcrumbList |

### 3.3 文件结构

```
xlx-web/
├── public/
│   ├── robots.txt          ← 新增
│   └── sitemap.xml         ← 新增
├── src/
│   ├── composables/
│   │   ├── useSEO.ts       ← 新增：SEO meta 管理
│   │   └── useJsonLd.ts    ← 新增：JSON-LD 结构化数据
│   └── ...
```

### 3.4 后台配置扩展

新增 site_config 字段：
- `seo_keywords` — SEO 关键词
- `seo_og_image` — OG 分享图片
- `seo_company_name` — SEO 公司名称
- `seo_phone` — SEO 联系电话
- `seo_address` — SEO 公司地址
