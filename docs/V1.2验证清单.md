## 前置条件

确保本地环境已启动：

```bash
# 终端 1：后端
cd xlx-api && mvn spring-boot:run -pl xlx-gateway

# 终端 2：前台
cd xlx-web && npm run dev

# 终端 3：后台
cd xlx-admin && npm run dev
```

- 前台访问：http://localhost:3000
- 后台访问：http://localhost:3001/admin/
- 后端 API：http://localhost:8080
