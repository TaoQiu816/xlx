# V1.2 界面美化与可视化规划

> 鑫连鑫丝网厂 B2B 官网 — UI 优化与增强
> 创建日期：2026-06-05
> 阶段定位：V1 功能已基本完成，提升系统可用性、界面专业度和本地稳定性

---

## 一、阶段目标

1. 后台管理端更清晰、更易用，适合非技术人员操作
2. 前台展示页更像正式工厂官网，提升专业感
3. 移动端不出现布局错乱
4. 不破坏 V1 原有功能，不引入 V2 功能

---

## 二、明确不做的功能

| 不做 | 原因 |
|------|------|
| 中英文切换 | V2.1 范围 |
| 询价车 / 购物车 | V2.2 范围 |
| 客户注册 / 客户中心 | V2.3 范围 |
| 在线支付 | 不在 V1-V2 范围 |
| 多角色权限 | V1 不做 |
| Docker Compose / Nginx 部署 | V1.4 范围，暂缓 |
| CI/CD（GitHub Actions） | 项目未进入多人协作阶段 |
| 完整前端单元测试 | 界面还在调整，测试易频繁改动 |
| 复杂动画库（GSAP、Lottie） | 过重，不适合 B2B |
| 视频背景 Hero | 加载慢，工业站不适合 |
| 暗色模式 | 非必要，增加维护成本 |

## 四、后台管理端优化清单

### 4.1 Dashboard 可视化（优先级：最高）

**现状**：已有基础卡片和图表，但数据来源不可扩展。

**优化方案**：

1. 新增后端接口 `GET /api/admin/dashboard/stats`，返回聚合数据
2. 前端不再拉 1000 条询盘计算趋势，改为读取接口返回的预聚合数据
3. 统计卡片增加「上架产品数」（当前只有产品总数）
4. 趋势图保持 7/30 天切换
5. 状态分布图保持

**新增接口设计**：

```
GET /api/admin/dashboard/stats

Response:
{
  "productTotal": 120,
  "productOnline": 95,
  "inquiryTotal": 340,
  "inquiryPending": 12,
  "inquiryTrend": [
    { "date": "2026-06-01", "count": 5 },
    { "date": "2026-06-02", "count": 8 }
  ],
  "inquiryStatus": [
    { "status": "new", "label": "新询盘", "count": 12 },
    { "status": "contacted", "label": "已联系", "count": 25 }
  ],
  "latestInquiries": [
    { "id": 1, "name": "张三", "company": "XX公司", "productName": "镀锌铁丝", "status": "new", "createdAt": "2026-06-05 10:30:00" }
  ]
}
```

**涉及文件**：
- 新增 `xlx-api/.../controller/admin/DashboardController.java`
- 新增 `xlx-api/.../dto/DashboardStats.java`
- 修改 `xlx-admin/src/views/Dashboard.vue`

### 5.5 轻量动画规范

**允许**：
- 按钮 hover 阴影/位移
- 卡片 hover 阴影增强
- 图片 hover 轻微放大（scale 1.02-1.05）
- 模块淡入（IntersectionObserver）
- FAQ 展开折叠
- 导航吸顶过渡（box-shadow）

**禁止**：
- 粒子动画
- 复杂 3D 效果
- 大面积动效
- 视频背景
- 影响加载速度的动画库

**技术实现**：仅 CSS transition + IntersectionObserver，不引入动画库

**尊重 reduced-motion**：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 六、是否需要新增接口

| 接口 | 用途 | 必要性 |
|------|------|--------|
| `GET /api/admin/dashboard/stats` | Dashboard 聚合数据 | 必须（解决客户端拉 1000 条数据的问题） |
| `GET /api/public/products/{slug}/related` | 产品详情页相关推荐 | 建议 |
| `PUT /api/admin/inquiries/{id}/status` | 询盘列表页内联改状态 | 建议（减少跳转） |

其他优化（搜索、排序）可通过现有列表接口增加 query 参数实现，无需新增接口。
