## 十四、结论与建议

### 14.1 英文内容缺失重点

1. **SiteConfig 英文后台入口缺失（P0）** — V8 迁移已插入 24 个英文 config 值，但 SiteConfig.vue 仅暴露了 `company_name_en`，其余 23 个英文字段无法在后台编辑
2. **FAQ JSON 结构不支持英文（P1）** — home_faq_items 和 faq_page_groups 的 JSON 结构缺少 qEn/aEn/titleEn 字段
3. **About.vue 硬编码（P1）** — 3 段公司介绍硬编码在前端，无法配置

### 14.2 是否建议先迁移 About.vue 硬编码内容

**建议迁移。** 理由：
- 3 段文字是公司核心介绍，英文版必须准确
- 迁移后管理员可在后台编辑中英文版本
- 与首页、FAQ 保持一致的可配置模式
- 工作量小（新增 2-3 个 config_key + 修改 About.vue）

### 14.3 是否可以进入 V2.2 询价车规划

**可以。** 英文内容补齐清单已整理完毕，大部分工作是管理员在后台填写数据（非代码开发）。SiteConfig 后台入口扩展和 FAQ JSON 结构扩展可与 V2.2 询价车规划并行推进，不构成阻塞。
