# V2.6.1 前台 API 缓存优化

**日期：** 2026-06-06
**目标：** 减少前台页面切换时重复请求公共 GET 接口

---

## 一、变更概述

新增前端轻量缓存层，对前台 6 个公开 GET 接口启用 sessionStorage 缓存，减少页面切换时的重复网络请求。

**不涉及：** 后端改动、Redis、新组件库、新业务功能。

## 二、缓存实现

### 文件变更

| 文件 | 变更 |
|------|------|
| `xlx-web/src/utils/apiCache.ts` | 新增：缓存工具（key 生成、TTL、sessionStorage、请求去重、清除） |
| `xlx-web/src/api/site.ts` | 修改：6 个 GET 方法接入 cachedRequest |

### 缓存工具能力

- **请求 key** = URL + query params + 当前语言 lang
- **TTL 过期**：过期后自动清除，下次请求重新获取
- **请求去重**：同一 key 并发请求时复用同一个 Promise
- **sessionStorage 持久化**：刷新页面后缓存仍在（TTL 内）
- **语言隔离**：中文和英文各自独立缓存
- **失败安全**：网络请求失败不写入缓存
- **解析容错**：sessionStorage 解析失败自动清理对应 key
- **手动清除**：`clearCache(pattern?)` 和 `clearAllCache()`

## 三、缓存范围

### 已缓存接口（6 个）

| 接口 | TTL | 说明 |
|------|-----|------|
| GET /config | 10 分钟 | 站点配置 |
| GET /categories | 10 分钟 | 产品分类 |
| GET /products | 3 分钟 | 产品列表（含分页/筛选参数） |
| GET /products/featured | 3 分钟 | 推荐产品 |
| GET /products/{slug} | 5 分钟 | 产品详情 |
| GET /factory-images | 10 分钟 | 工厂图片 |
| GET /certificates | 10 分钟 | 证书列表 |

### 未缓存接口

| 接口 | 原因 |
|------|------|
| POST /inquiries | 询盘提交，数据变更 |
| POST /upload | 文件上传，数据变更 |
| /api/admin/** | 后台接口，不缓存 |

## 四、语言切换处理

- 缓存 key 包含当前语言：`/products|{"page":1}|zh` vs `/products|{"page":1}|en`
- 中英文缓存完全隔离
- 切换语言后自动读取对应语言缓存，无缓存则正常请求
- 不会中英文内容错乱

## 五、数据一致性

当前采用 TTL 保证最终一致性：

- 管理员后台修改配置/产品/证书/工厂图后，前台最多存在 3-10 分钟缓存延迟
- 本地开发可通过刷新页面或清空 sessionStorage 立即查看最新数据
- 后续如需更强一致性，可考虑 cache version 或后端缓存失效机制

## 七、收口修复（V2.6.1 收口）

### 1. allowedHosts 安全修复

- **问题**：`allowedHosts: true` 允许任意 host 访问，存在安全风险
- **修复**：改为从 `VITE_ALLOWED_HOSTS` 环境变量读取白名单，默认只允许 `localhost` 和 `127.0.0.1`
- **远程调试**：设置 `VITE_ALLOWED_HOSTS=localhost,127.0.0.1,your-domain.com` 即可
- **新增文件**：`xlx-web/.env.example`、`xlx-admin/.env.example`
