# V2.2 询价车功能规划

> 版本：V2.2
> 创建时间：2026-06-06
> 状态：规划中

## 1. 功能概述

询价车（Inquiry Cart）是 B2B 场景下的"购物车"，客户可以将多个产品加入询价车，统一填写联系方式和需求后一次性提交询盘，提升询盘效率。

### 核心价值
- 客户可批量咨询多个产品，减少重复填写
- 管理员可收到结构化的批量询盘
- 提升客户体验，降低询盘门槛

### 与 V1 询盘系统的区别
| 特性 | V1 单品询盘 | V2.2 询价车 |
|------|------------|-------------|
| 产品数量 | 单个产品 | 多个产品 |
| 提交方式 | 产品详情页直接提交 | 询价车统一提交 |
| 客户信息 | 每次填写 | 首次填写后缓存 |
| 后台展示 | 独立询盘记录 | 按询价车分组展示 |

## 2. 技术方案

### 2.1 存储方案

采用 **localStorage + 后端 API** 双层方案：

- **localStorage**: 客户未登录时，询价车数据存储在浏览器本地
- **后端 API**: 提交询盘时，后端接收完整的询价车数据

选择理由：
- 客户无需注册即可使用询价车（B2B 场景，客户不希望强制注册）
- localStorage 零后端成本，适合初期
- 提交时一次性传给后端，无需维护购物车状态

### 2.3 API 设计

#### 提交询价车

```
POST /api/public/inquiry/cart
Content-Type: application/json

Request Body: InquiryCartSubmitDTO
Response: { success: boolean, data: { id: number, inquiryNo: string } }
```

**后端处理逻辑**：
1. 验证联系人信息必填字段
2. 验证至少有一个产品
3. 创建主询盘记录（contact 信息）
4. 为每个产品创建关联的询盘明细
5. 生成询盘编号（格式：INQ-YYYYMMDD-XXXX）
6. 返回询盘 ID 和编号

### 2.4 数据库设计

#### 方案 A：扩展现有 inquiry 表（推荐）

在现有 `inquiry` 表基础上增加字段：

```sql
-- V9__add_inquiry_cart_fields.sql
ALTER TABLE inquiry
  ADD COLUMN inquiry_no VARCHAR(32) COMMENT '询盘编号' AFTER id,
  ADD COLUMN cart_id VARCHAR(64) COMMENT '询价车会话ID（用于分组）' AFTER inquiry_no,
  ADD COLUMN source VARCHAR(20) DEFAULT 'single' COMMENT '来源：single-单品询盘/cart-询价车' AFTER cart_id,
  ADD COLUMN parent_id BIGINT COMMENT '主询盘ID（明细记录指向主记录）' AFTER source;

CREATE INDEX idx_inquiry_cart_id ON inquiry(cart_id);
CREATE INDEX idx_inquiry_parent_id ON inquiry(parent_id);
```

**数据示例**：
```
| id | inquiry_no      | cart_id       | source | parent_id | product_id | product_name |
|----|-----------------|---------------|--------|-----------|------------|--------------|
| 1  | INQ-20260606-0001 | abc123     | cart   | NULL      | NULL       | NULL         |  ← 主记录（联系人+总备注）
| 2  | NULL            | abc123        | cart   | 1         | 1          | 镀锌铁丝     |  ← 明细1
| 3  | NULL            | abc123        | cart   | 1         | 5          | 电焊网片     |  ← 明细2
```

#### 方案 B：新建 inquiry_cart 表（备选）

```sql
CREATE TABLE inquiry_cart (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  cart_id VARCHAR(64) NOT NULL COMMENT '购物车会话ID',
  product_id BIGINT NOT NULL,
  product_name VARCHAR(200),
  quantity VARCHAR(100),
  specification TEXT,
  note TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**选择方案 A 的理由**：
- 复用现有 inquiry 表，减少表数量
- 后台查询逻辑统一，不需要 JOIN 新表
- parent_id 自然形成主从关系
- 单品询盘和询价车共用同一套状态流转

#### InquiryCartService

```java
@Service
public class InquiryCartService {

    private final InquiryMapper inquiryMapper;

    public InquiryCartService(InquiryMapper inquiryMapper) {
        this.inquiryMapper = inquiryMapper;
    }

    @Transactional
    public InquirySubmitResult submit(InquiryCartSubmitDTO dto) {
        String cartId = UUID.randomUUID().toString().replace("-", "").substring(0, 16);
        String inquiryNo = generateInquiryNo();

        // 1. 创建主询盘记录
        Inquiry master = new Inquiry();
        master.setInquiryNo(inquiryNo);
        master.setCartId(cartId);
        master.setSource("cart");
        master.setName(dto.contact().name());
        master.setCompany(dto.contact().company());
        master.setPhone(dto.contact().phone());
        master.setEmail(dto.contact().email());
        master.setWechat(dto.contact().wechat());
        master.setWhatsapp(dto.contact().whatsapp());
        master.setCountry(dto.contact().country());
        master.setMessage(dto.message());
        master.setFileUrl(dto.fileUrl());
        master.setStatus("new");
        inquiryMapper.insert(master);

        // 2. 创建明细记录
        for (InquiryCartSubmitDTO.CartItem item : dto.items()) {
            Inquiry detail = new Inquiry();
            detail.setParentId(master.getId());
            detail.setCartId(cartId);
            detail.setSource("cart");
            detail.setProductId(item.productId());
            detail.setProductName(item.productName());
            detail.setQuantity(item.quantity());
            detail.setSpecification(item.specification());
            detail.setRemark(item.note());
            detail.setStatus("new");
            detail.setCreatedAt(LocalDateTime.now());
            inquiryMapper.insert(detail);
        }

        return new InquirySubmitResult(master.getId(), inquiryNo);
    }

    private String generateInquiryNo() {
        String date = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyyMMdd"));
        // 查询当日最大编号 +1
        long todayCount = inquiryMapper.countTodayInquiries(date);
        return String.format("INQ-%s-%04d", date, todayCount + 1);
    }
}
```

#### InquiryCartController

```java
@RestController
@RequestMapping("/api/public/inquiry")
public class InquiryCartController {

    private final InquiryCartService inquiryCartService;

    public InquiryCartController(InquiryCartService inquiryCartService) {
        this.inquiryCartService = inquiryCartService;
    }

    @PostMapping("/cart")
    public ApiResponse<?> submitCart(@Valid @RequestBody InquiryCartSubmitDTO dto) {
        var result = inquiryCartService.submit(dto);
        return ApiResponse.ok(result);
    }
}
```

#### useInquiryCart.ts

```typescript
import { ref, computed } from 'vue'

const STORAGE_KEY = 'xlx_inquiry_cart'

interface InquiryCartItem {
  productId: number
  productName: string
  productImage: string
  quantity: string
  specification: string
  note: string
  addedAt: number
}

interface InquiryContact {
  name: string
  company: string
  phone: string
  email: string
  wechat: string
  whatsapp: string
  country: string
}

const items = ref<InquiryCartItem[]>([])
const contact = ref<InquiryContact | null>(null)

function load() {
  try {
    const raw = localStorage.getItem(STORAGE_KEY)
    if (raw) {
      const data = JSON.parse(raw)
      items.value = data.items || []
      contact.value = data.contact || null
    }
  } catch { /* ignore */ }
}

function save() {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify({
      items: items.value,
      contact: contact.value,
    }))
  } catch { /* ignore */ }
}

export function useInquiryCart() {
  const count = computed(() => items.value.length)

  function addItem(item: Omit<InquiryCartItem, 'addedAt'>) {
    const exists = items.value.find(i => i.productId === item.productId)
    if (!exists) {
      items.value.push({ ...item, addedAt: Date.now() })
      save()
    }
  }

  function removeItem(productId: number) {
    items.value = items.value.filter(i => i.productId !== productId)
    save()
  }

  function updateItem(productId: number, data: Partial<InquiryCartItem>) {
    const item = items.value.find(i => i.productId === productId)
    if (item) {
      Object.assign(item, data)
      save()
    }
  }

  function setContact(data: InquiryContact) {
    contact.value = data
    save()
  }

  function clear() {
    items.value = []
    contact.value = null
    save()
  }

  async function submit(message: string, fileUrl?: string) {
    if (!contact.value) throw new Error('请填写联系信息')
    if (items.value.length === 0) throw new Error('询价车为空')

    const res = await fetch('/api/public/inquiry/cart', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        contact: contact.value,
        items: items.value.map(i => ({
          productId: i.productId,
          productName: i.productName,
          quantity: i.quantity,
          specification: i.specification,
          note: i.note,
        })),
        message,
        fileUrl: fileUrl || '',
      }),
    })

    if (!res.ok) throw new Error('提交失败')
    const data = await res.json()
    if (data.success) {
      clear()
      return data.data
    }
    throw new Error(data.error || '提交失败')
  }

  // 初始化时加载
  load()

  return {
    items,
    contact,
    count,
    addItem,
    removeItem,
    updateItem,
    setContact,
    clear,
    submit,
  }
}
```

## 3. 用户流程

### 3.1 客户端流程

```
1. 浏览产品 → 点击"加入询价车"
2. 继续浏览 → 继续添加其他产品
3. 点击导航栏"询价车"图标 → 打开抽屉
4. 查看已添加产品 → 调整数量/规格/备注
5. 填写联系信息（首次填写后缓存）
6. 填写总体留言 → 提交
7. 显示成功提示 → 生成询盘编号
```

### 3.2 管理端流程

```
1. 询盘列表 → 筛选"询价车"来源
2. 查看主询盘记录 → 联系人信息 + 总备注
3. 展开明细 → 查看各产品具体需求
4. 统一报价 → 联系客户
5. 更新状态 → quoted → sample_confirmed → order_confirmed
```

## 6. 风险与注意事项

1. **localStorage 清除风险**：客户清除浏览器数据会丢失询价车，可接受（B2B 场景，客户通常会尽快提交）
2. **并发提交**：同一客户多次提交不会冲突，每次提交生成独立 cart_id
3. **数据一致性**：提交时校验产品是否存在，避免无效关联
4. **向后兼容**：单品询盘功能不受影响，source 字段默认 'single'
