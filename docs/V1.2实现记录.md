#### IntersectionObserver 模式

使用 `setSectionRef` 模式避免 TypeScript 编译错误：

```typescript
const sectionRefs: Record<string, Element | null> = {}
const setSectionRef = (key: string) => (el: any) => { sectionRefs[key] = el }

onMounted(() => {
  Object.entries(sectionRefs).forEach(([key, el]) => {
    if (!el) return
    const observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        el.classList.add('animate-in')
        observer.unobserve(el)
      }
    }, { threshold: 0.1 })
    observer.observe(el)
  })
})
```

## 五、动画规格

| 效果 | 属性 | 时长 |
|------|------|------|
| 按钮 hover 上浮 | transform: translateY(-1px) | 200ms |
| 卡片 hover 上浮 | transform: translateY(-4px) + box-shadow | 200ms |
| 产品图片放大 | transform: scale(1.05) | 500ms |
| 产品遮罩滑入 | opacity 0→1 + translateY(10px→0) | 300ms |
| FAQ 展开收起 | max-height 动画 | 300ms |
| 箭头旋转 | transform: rotate(180deg) | 300ms |
| 页面过渡 | opacity 淡入淡出 | 200ms |
| 返回顶部按钮 | opacity 淡入淡出 | 200ms |
| Header 阴影 | box-shadow | 200ms |
| 滚动淡入 | opacity + translateY(20px→0) | 500ms |

**所有动画仅使用 compositor-friendly 属性（transform、opacity），不影响布局性能。**
