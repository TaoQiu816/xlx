# 丝网工厂官网与销售系统 V1 实现步骤

## 0. 当前实现边界

### 0.1 本阶段只做 V1

V1 目标：

```text
中文前台展示网站
+
中文后台管理系统
+
产品分类管理
+
产品信息管理
+
产品规格管理
+
产品图片管理
+
工厂图片管理
+
证书管理
+
客户询盘管理
+
文件上传
+
移动端适配
+
中英文字段预留
+
订单/支付扩展预留
```

### 0.2 V1 不做内容

```text
在线支付
完整购物车
客户注册
客户中心
多销售人员 CRM
自动运费计算
多币种
海外支付
自动报价
复杂订单流程
AI 客服
ERP 对接
正式多语言上线
```

### 0.3 技术栈建议

优先采用：

```text
前台：Vue 3 + Vite + Tailwind CSS
后台：Vue 3 + Vite + Element Plus
后端：Node.js + NestJS / Express
数据库：MySQL
ORM：Prisma
文件上传：本地 uploads 目录，后续可迁移对象存储
接口鉴权：JWT
部署：Docker Compose
```

如果更熟悉 Java，也可以把后端换成：

```text
Spring Boot + MyBatis Plus + MySQL
```

但为了配合 Claude Code CLI 快速生成和迭代，建议第一版使用：

```text
Vue 3 + Node.js + Prisma + MySQL
```

# 2. Claude Code CLI 使用方式

## 2.1 初始化项目目录

```bash
mkdir wire-mesh-website
cd wire-mesh-website
git init
mkdir docs apps packages uploads
```

把上传的需求文档放入：

```text
docs/requirements.md
```

## 2.2 创建 CLAUDE.md

在项目根目录创建 `CLAUDE.md`，用于约束 Claude Code CLI 的行为。

```markdown
# CLAUDE.md

## 项目定位

本项目是一个丝网工厂官网与销售系统。V1 只实现中文前台展示、中文后台管理、产品管理、规格管理、图片管理、证书管理、询盘管理和文件上传。

## 严格边界

V1 不实现：
- 在线支付
- 完整购物车
- 客户注册
- 客户中心
- 多币种
- 海外支付
- AI 客服
- ERP 对接
- 正式多语言上线

但必须预留：
- 中英文字段
- 询价车扩展
- 订单扩展
- 支付扩展
- 客户注册扩展

## 技术栈

优先使用：
- Vue 3 + Vite + Tailwind CSS 开发前台
- Vue 3 + Vite + Element Plus 开发后台
- Node.js + Express 或 NestJS 开发后端
- Prisma + MySQL 管理数据库
- JWT 做后台登录鉴权
- Multer 或同类方案处理文件上传

## 页面风格

前台要求：
- 简洁
- 工业风
- B2B
- 工厂感
- 移动端友好
- 不使用复杂动画
- 不使用廉价模板感强的视觉

后台要求：
- 中文界面
- 菜单简单
- 表单清楚
- 适合非技术人员维护产品
- 删除操作需要二次确认

## 开发规则

1. 不要一次性实现 V2/V3/V4 功能。
2. 每次改动前先阅读 docs/requirements.md。
3. 产品数据不得写死，必须从数据库读取。
4. 图片和文件上传必须限制格式和大小。
5. 后台接口必须鉴权。
6. 前台接口只开放必要展示数据。
7. 所有列表页需要分页。
8. 所有后台删除操作必须二次确认。
9. 所有表单必须做基础校验。
10. 每完成一个阶段，更新 README.md 和 docs/acceptance-checklist.md。
```
