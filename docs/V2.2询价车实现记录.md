# V2.2 询价车实现记录

**实现日期：** 2026-06-06

## 功能概述

在 V2.1 中英文切换基础上，新增询价车功能，支持客户在前台同时选择多个产品一次性提交询价。

## 实现步骤

### Step 1：数据库与后端基础

- 新增 Flyway 迁移 `V9__add_inquiry_item.sql`，创建 `inquiry_item` 表
- 新增 `InquiryItem` 实体（`@TableLogic` 逻辑删除）
- 新增 `InquiryItemMapper`
- 新增 `InquiryItemService`（listByInquiryId / createBatch / deleteByInquiryId）
- `InquiryService` 新增 `createWithItems` 方法（`@Transactional`）
- 后端测试 15 项全部通过

### Step 2：提交接口多产品支持

- `PublicController.submitInquiry` 参数改为 `InquirySubmitRequest`
- 新增 `CartItemDTO` 内部类，字段长度验证（productNameCn ≤200，quantity ≤100，specification ≤500）
- items 数量上限 20（`@Size(max=20)` + 手动校验）
- 多产品时清空 inquiry 主表的 product_id/product_name/quantity/specification，写入 inquiry_item
- 单产品向后兼容，走原 `create(Inquiry)` 逻辑

### Step 3：后台询盘详情多产品展示

- `InquiryController.getDetail` 返回 `{inquiry, items}` 结构
- `InquiryDetail.vue` 新增 items 表格（productNameCn/En、quantity、specification）
- `Inquiries.vue` 列表中多产品询盘显示"多产品"标签

### Step 4：前台询价车

- **composables/useQuoteCart.ts** — localStorage 持久化（key: `xlx_quote_cart`）
- **composables/useToast.ts** — 轻量级 Toast 通知
- **components/ToastContainer.vue** — Toast 渲染容器
- **views/QuoteCart.vue** — 询价车页面（产品列表、数量/规格输入、联系表单、提交）
- **views/Products.vue** — 产品卡片右下角"加入询价"按钮
- **views/ProductDetail.vue** — "加入询价"按钮 + 已加入状态
- **components/Header.vue** — 导航栏购物车图标 + 红色数量徽章
- **router/index.ts** — 新增 `/quote-cart` 路由
- **locales/zh.ts / en.ts** — 新增 `quoteCart.*` 翻译

## 技术决策

| 决策 | 理由 |
|------|------|
| 新建 inquiry_item 表 | 不修改已执行迁移，不扩展 inquiry 表字段 |
| localStorage 草稿 | 不登录状态下不保存后端草稿，降低复杂度 |
| 轻量 Toast 替代 ElMessage | xlx-web 不依赖 element-plus，保持轻量 |
| @Transactional 写入 | 保证 inquiry + inquiry_item 原子性 |
| 单产品向后兼容 | 保留 inquiry.product_id/product_name 字段 |

### Step 5：收口与体验优化

- Toast 通知添加图标（success/info/error）
- 询价车空状态添加引导文案和图标
- 提交成功后显示成功图标、引导文案和"浏览产品"按钮
- 产品列表"加入询价"按钮增大触摸区域（44px）和按压反馈
- 后台产品明细表格添加序号列、条纹样式、空值处理
- 新增 `emptyHint`、`submitSuccessHint` 翻译
- 新增 `useToast` composable 和 `ToastContainer.vue` 组件
