# 真实内容后台录入指南

**创建日期：** 2026-06-06
**用途：** 指导管理员在后台录入真实内容

---

## 录入前准备

1. 准备好所有真实素材：产品图片、工厂图片、证书图片、公司介绍文字
2. 图片提前压缩（推荐 TinyPNG），控制在 10MB 以内
3. 准备好中英文双语内容
4. 确保本地服务已启动（后端 8080，后台 3001）

## 2. 首页内容

**后台位置：** 站点配置 → 首页 Banner

| 配置项 | 中文 | 英文 | 说明 |
|--------|------|------|------|
| Banner 标题 | 如"专业丝网制造商" | 如"Professional Wire Mesh Manufacturer" | 首页大标题 |

| 组 | 示例(中) | 示例(英) | 说明 |

## 4. 产品分类

**后台位置：** 分类管理

每个分类需填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 分类名称(中) | 中文分类名 | 不锈钢丝网 |
| 分类名称(英) | 英文分类名 | Stainless Steel Wire Mesh |
| slug | URL 标识，小写英文+连字符 | stainless-steel-mesh |
| 排序 | 数字越小越靠前 | 1 |

**操作步骤：**
1. 点击「添加分类」
2. 填写中英文名称和 slug
3. 设置排序
4. 保存

**验收方式：** 打开前台产品中心，确认分类筛选正常。

---

## 5. 产品信息

**后台位置：** 产品管理 → 添加/编辑产品

### 5.1 基本信息标签页

| 字段 | 说明 | 必填 |
|------|------|------|
| 产品名称(中) | 如"304 不锈钢丝网" | ✅ |
| 产品名称(英) | 如"304 Stainless Steel Wire Mesh" | ✅ |
| slug | 如 `304-stainless-steel-wire-mesh` | ✅ |
| 所属分类 | 下拉选择 | ✅ |
| 简短描述(中) | 一行描述，显示在列表 | ✅ |
| 简短描述(英) | 一行描述 | ✅ |
| 详细描述(中) | 产品详细介绍，支持换行 | ✅ |
| 详细描述(英) | 产品详细介绍 | ✅ |
| 主图 | 产品白底图，800x800px | ✅ |
| 状态 | 上线/下线 | ✅ |
| 推荐产品 | 是否在首页展示 | 选填 |

### 5.2 价格标签页

| 字段 | 说明 | 必填 |
|------|------|------|
| 价格 | 如 5.00 | 选填 |
| 单位 | 如 kg、m² | 选填 |
| 显示价格 | 前台是否显示价格 | 选填 |
| 支持定制 | 是否支持定制 | 选填 |
| 支持询价 | 是否支持询价 | 选填 |
| MOQ | 最小起订量 | 选填 |

### 5.3 规格标签页

动态表格，每行一组规格：

| 字段 | 说明 | 示例 |
|------|------|------|
| 规格名(中) | 如"材质" | 材质 |
| 规格名(英) | 如"Material" | Material |
| 规格值(中) | 如"304 不锈钢" | 304 不锈钢 |
| 规格值(英) | 如"304 Stainless Steel" | 304 Stainless Steel |
| 排序 | 数字越小越靠前 | 1 |

点击「+ 添加规格」增加行，点击删除图标移除行。

### 5.4 图片标签页

上传多张产品详情图，支持拖拽排序。

### 5.5 应用与包装标签页

| 字段 | 说明 |
|------|------|
| 应用领域(中/英) | 如"建筑围栏、公路护栏" |
| 包装方式(中/英) | 如"编织袋包装，防潮处理" |

### 5.6 扩展标签页

| 字段 | 说明 |
|------|------|
| 证书说明(中/英) | 如"ISO 9001 认证" |
| 排序权重 | 数字越大越靠前 |

**验收方式：** 打开前台产品列表和详情页，确认产品信息、规格表、图片正常显示。

## 6. 产品规格

**录入位置：** 产品编辑页 → 规格标签页

操作步骤：
1. 进入产品编辑页
2. 点击「规格」标签
3. 点击「+ 添加规格」
4. 填写规格名和规格值（中英文）
5. 设置排序
6. 保存

**验收方式：** 打开产品详情页，确认规格表格显示正确。

---

## 7. 产品图片

**上传位置：** 产品编辑页 → 图片标签页 + 基本信息标签页（主图）

**图片规范：**

| 图片类型 | 建议尺寸 | 大小限制 | 格式 |
|----------|----------|----------|------|
| 主图 | 800x800px | ≤ 500KB | JPG/WebP |
| 详情图 | 1200px 宽 | ≤ 1MB | JPG/WebP |

**操作步骤：**
1. 进入产品编辑页
2. 在基本信息标签页上传主图
3. 切换到图片标签页上传详情图
4. 拖拽调整图片顺序
5. 保存

**验收方式：** 打开产品列表（主图）和详情页（图片轮播），确认图片正常显示。

## 10. FAQ

- 中文问题

## 11. 邮件通知

**后台位置：** 站点配置 → 邮件通知配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 启用邮件通知 | 开关控制 | 先关闭，配好后开启 |
| SMTP 服务器 | 邮箱 SMTP 地址 | smtp.qq.com |
| SMTP 端口 | 通常 587 | 587 |
| 发件人邮箱 | 用于发送通知的邮箱 | your@qq.com |
| 邮箱密码/授权码 | QQ 邮箱用授权码 | xxxxxxxx |
| 发件人显示名称 | 邮件标题中的发件人 | 鑫连鑫丝网 |
| 收件人邮箱 | 管理员邮箱 | admin@company.com |
| 启用 TLS | 通常开启 | true |

**操作步骤：**
1. 先填写 SMTP 配置
2. 保存配置
3. 开启「启用邮件通知」
4. 保存
5. 提交一条测试询盘
6. 检查管理员邮箱是否收到通知

**验收方式：** 提交询盘后管理员收到邮件通知。

## 12. SEO

**后台位置：** 站点配置 → SEO 配置

| 配置项 | 说明 | 建议 |
|--------|------|------|
| SEO 标题(中) | 页面标题，60 字符内 | 包含公司名+核心业务 |
| SEO 标题(英) | 页面标题 | 如"Xinlianxin Wire Mesh - Professional Manufacturer" |
| SEO 描述(中) | 150-160 字符 | 包含核心关键词 |
| SEO 描述(英) | 150-160 字符 | 同上英文版 |
| SEO 关键词(中) | 逗号分隔 | 如"丝网,不锈钢丝,镀锌铁丝" |
| SEO 关键词(英) | 逗号分隔 | 如"wire mesh,stainless steel wire" |
| OG 分享图片 | 社交分享图 | 1200x630px |

**产品 SEO：** 每个产品的 slug 会自动生成 SEO 友好的 URL。

**验收方式：** 查看浏览器标签页标题、右键查看页面源码中的 meta 标签。

## 录入顺序建议

| 顺序 | 内容 | 原因 |
|------|------|------|
| 1 | 站点基本信息 + 联系方式 | 其他页面依赖这些信息 |
| 2 | 产品分类 | 产品依赖分类 |
| 3 | 产品信息 + 规格 + 图片 | 核心内容 |
| 4 | 首页 Banner + Hero + 卖点 | 首页展示 |
| 5 | 工厂图片 + 证书 | 关于我们/工厂/证书页面 |
| 6 | FAQ | 首页 + FAQ 页面 |
| 7 | SEO 配置 | 页面 meta 信息 |
| 8 | 邮件通知 | 提交询盘后通知 |
| 9 | 管理员密码修改 | 安全 |
