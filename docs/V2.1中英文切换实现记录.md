## 一、实施目标

实现前台中英文切换功能，包括：
1. vue-i18n 国际化框架搭建
2. UI 标签翻译（导航、按钮、表单等）
3. 实体字段双语支持（产品名称、描述等）
4. SiteConfig 英文配置
5. SEO 语言适配
6. 语言切换器组件

**技术约束：** 使用 `vue-i18n@9` Composition API 模式（`legacy: false`），语言选择持久化到 localStorage。

---

| UI 标签 | `vue-i18n` `$t()` | 导航、按钮、表单标签、提示文字 |

## 三、实现详情

### 3.1 vue-i18n 初始化

**文件：** `xlx-web/src/i18n.ts`

- 初始化 `createI18n`，`legacy: false`（Composition API 模式）
- 语言选择从 localStorage 读取，默认中文
- 导出 `setLocale(lang)` 和 `getLocale()` 工具函数
- 注册到 `main.ts`：`app.use(i18n)`

### 3.2 语言包

**文件：** `xlx-web/src/locales/zh.ts`、`xlx-web/src/locales/en.ts`

### 3.3 langField 工具

**文件：** `xlx-web/src/composables/useLangField.ts`

```typescript
export function langField<T extends Record<string, unknown>>(obj: T, base: string): string
```

- 根据当前 locale 选择 `baseEn` 或 `baseCn` 字段
- 回退到 `baseCn`（兜底中文）
- 用于：产品名称、分类名称、规格名称/值、证书标题/描述、工厂图片标题/描述

### 3.4 Header 语言切换

**文件：** `xlx-web/src/components/Header.vue`

- 导航项从静态数组改为 `computed`，使用 `t()` 生成
- 添加语言切换按钮（EN/中），点击调用 `setLocale()`
- 移动端菜单中也包含切换按钮

### 3.5 SEO 语言适配

**文件：** `xlx-web/src/composables/useSEO.ts`

- `siteName` 根据 locale 选择中文/英文
- `description` 使用对应语言的默认值
- `ogLocale` 设置为 `zh_CN` 或 `en_US`
- `htmlAttrs.lang` 设置为 `zh-CN` 或 `en`

### 3.6 后台 SiteConfig 英文字段

**文件：** `xlx-gateway/.../V8__add_english_site_config.sql`

新增配置项：

| Key | 说明 |
|-----|------|
| `site_name_en` | 网站英文名称 |
| `company_name_en` | 公司英文名称 |
| `banner_title_en` | 首页横幅英文标题 |
| `banner_subtitle_en` | 首页横幅英文副标题 |
| `phone_en` / `email_en` / `address_en` | 联系信息英文 |
| `hero_stat1_title_en` ~ `hero_stat4_title_en` | 首页数据统计英文 |
| `sp1_title_en` ~ `sp4_title_en` | 卖点英文 |
| `seo_title_en` / `seo_description_en` / `seo_keywords_en` | SEO 英文 |

### 3.7 后台管理补充

- `FactoryImages.vue` 添加 `descriptionEn` 表单字段
- `Certificates.vue` 添加 `descriptionEn` 表单字段
