## 四、安全配置检查项

### 4.1 已修复（V2.4 代码变更）

| 问题 | 严重度 | 修复方式 |
|------|--------|----------|
| `GET /api/public/config` 暴露 SMTP 密码 | CRITICAL | 新增 `getPublicConfigMap()` 过滤敏感键 |
| 文件上传大小限制不一致（app 50MB vs servlet 10MB） | INFO | 统一为 10MB |
| 文件扩展名黑名单不完整（缺 html/svg） | LOW | 补充 html/htm/svg/jsp/asp/aspx |
| 上传大小错误信息写死 "10MB" | LOW | 改为动态计算 |

### 4.2 需要上线前手动配置

| 项目 | 说明 | 操作 |
|------|------|------|
| JWT_SECRET | 当前默认值已知，必须覆盖 | 设置环境变量 `JWT_SECRET=<随机64字节>` |
| DB_PASSWORD | 当前默认 root，必须覆盖 | 设置环境变量 `DB_PASSWORD=<强密码>` |
| CORS_ORIGINS | 当前默认 localhost，必须覆盖 | 设置环境变量 `CORS_ORIGINS=https://your-domain.com` |
| 管理员密码 | 默认 admin/admin123 | 后台首次登录后立即修改 |
| MySQL 用户 | 当前使用 root | 创建专用用户 `xlx_app`，仅授予 SELECT/INSERT/UPDATE/DELETE |
| SMTP 配置 | 当前为空 | 后台「站点配置 → 邮件通知配置」填写 |

### 4.3 建议但非阻塞

| 项目 | 说明 | 优先级 |
|------|------|--------|
| 速率限制 | 询盘提交和文件上传无速率限制 | MEDIUM（可由 Nginx/CDN 层实现） |
| 安全响应头 | 缺少 CSP/X-Frame-Options 等 | MEDIUM（可由 Nginx/CDN 层实现） |
| 登录失败锁定 | 无限次密码尝试 | MEDIUM（可由 Nginx 层实现） |
| SQL 日志 | 当前 StdOutImpl 输出所有 SQL | LOW（上线前改为 WARN 或关闭） |
| useSSL | 数据库连接未加密 | LOW（同机部署可接受） |
