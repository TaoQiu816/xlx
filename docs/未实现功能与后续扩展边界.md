# 未实现功能与后续扩展边界

**创建日期：** 2026-06-06
**用途：** 明确当前不需要的功能、暂不接入的功能，划定开发边界

---

## 一、当前项目不需要（不纳入近期规划）

以下功能经评估后明确不需要，不纳入近期规划：

| 功能 | 不需要的原因 |
|------|-------------|
| AI 客服 | 丝网产品规格和报价需人工确认，AI 不能直接提升核心业务闭环，引入后增加成本和维护复杂度 |
| AI 推荐 | 产品量不大，当前以工厂展示、产品管理、询盘转化为主，推荐系统无实际业务价值 |
| AI 自动文案 | 产品描述需专业性和准确性，AI 生成文案质量不可控，不适用于 B2B 工业品场景 |
| AI 自动报价 | 丝网产品报价涉及规格、材质、数量、包装、运费、定制沟通等多因素，必须人工确认 |
| Elasticsearch | 产品量不大（预计 < 500），MySQL LIKE + 分类筛选已够用，引入 ES 增加运维成本 |
| 消息队列（RabbitMQ/Kafka） | 询盘量不大，邮件通知已用 @Async 异步，系统复杂度低，无需 MQ 解耦 |
| 复杂 CRM | 当前后台询盘管理已够用，客户量不足以支撑 CRM 系统，引入后增加使用和维护负担 |
| 自动报价系统 | 丝网产品报价需人工确认规格、包装、运费等因素，自动化不可行 |
| 复杂推荐系统 | 产品量小、客户量小，推荐系统无实际业务价值 |
| 大数据分析系统 | 当前数据量不足以支撑大数据分析，引入后无实际业务产出 |
| 微服务 | 单体应用足够满足需求，团队规模小，微服务运维成本高 |
| GraphQL | REST API 已满足前后端交互需求，前端页面固定，无需灵活查询 |

**总结：** 以上功能当前项目不需要，不纳入近期规划。原因统一为：产品量不大、丝网产品报价需人工确认、AI 功能不能直接提升核心业务闭环、引入后增加成本和维护复杂度。

## 二、当前阶段暂不接入，未来可按需接入

以下功能当前阶段暂不接入，但未来可根据业务需要按需接入：

### 2.1 部署与基础设施

| 功能 | 暂不接入的原因 | 后续触发条件 |
|------|----------------|-------------|
| Redis 缓存 | 当前访问量和数据量不大，MySQL 足够 | 产品 > 1000 或 QPS > 100 或需要分布式会话 |
| OSS/COS 对象存储 | 当前本地 uploads 足够，文件量和访问量上来后再迁移 | 文件 > 10GB 或需 CDN 加速或需多节点共享 |
| CDN | 域名未确认，国内访问速度可接受 | 域名确认后上线时配置 |
| Docker | 服务器环境未确认，单体应用部署简单 | 部署时根据服务器环境决定 |
| Nginx | 属于部署阶段，服务器确定后再做 | 服务器确认后 |
| CI/CD | 属于部署阶段，服务器确定后再做 | 服务器确认后 |

### 2.2 业务功能

| 功能 | 暂不接入的原因 | 后续触发条件 |
|------|----------------|-------------|
| 多角色权限 | 当前单管理员足够 | 管理员 > 3 人 |
| 客户注册 | 当前询盘不强制登录，降低客户提交门槛 | 客户量增加，需要客户自助查询询盘状态 |
| 客户中心 | 需等真实客户和询盘量增加后再做 | 询盘量 > 100/月 |
| 订单系统 | 当前不是完整商城，丝网产品需沟通后报价 | 产品标准化 + 支付接入后 |
| 支付系统 | 丝网产品存在规格确认、包装、运费、定制沟通，当前优先询盘 | 产品标准化后 |
| 报价单系统 | 后续如询盘量增加可做 | 询盘量 > 50/月 |
| 标准购物车 | 当前只做询价车，丝网产品需沟通后报价 | 产品标准化后 |

## 三、已知技术债务

| 项目 | 严重度 | 说明 | 处理建议 |
|------|--------|------|----------|
| JWT 无刷新机制 | LOW | 24h 后需重新登录 | 单管理员可接受 |
| Excel 导出不含多产品明细 | LOW | 仅导出询盘级数据 | 后续增强 |
| SQL 日志默认 StdOutImpl | LOW | 开发环境保留，生产环境通过 MYBATIS_LOG_IMPL 环境变量关闭 | 上线前设置 |
| 数据库 useSSL=false | LOW | 同机部署可接受 | 分离部署时开启 |
| 后台 UI 间距 | LOW | 部分页面间距不足 | 后续美化 |

## 四、后续扩展路径

### 阶段一：上线准备（非开发）

- 录入真实内容
- 配置服务器环境（MySQL、Nginx、HTTPS）
- 设置生产环境变量（JWT_SECRET、DB_PASSWORD、CORS_ORIGINS、MYBATIS_LOG_IMPL）
- 域名和 SSL 证书
- 替换 sitemap.xml/robots.txt 中的占位域名
- 管理员密码修改

### 阶段二：部署上线（服务器确认后）

- Docker 容器化
- Nginx 反向代理 + 安全头
- CI/CD 流水线
- CDN 配置
- Redis 缓存（如需要）
- OSS 对象存储（如需要）

### 阶段三：业务增长后

- 客户注册/客户中心
- 报价单系统
- 标准购物车
- 订单系统
- 支付系统
- 多角色权限
- 复杂 CRM

### 阶段四：规模化后（如需要）

- Elasticsearch 搜索
- 大数据分析
- ERP 对接
