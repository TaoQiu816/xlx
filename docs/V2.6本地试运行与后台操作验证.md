## 本轮允许修改的范围

| 类型 | 说明 |
|------|------|
| 表单提示文字 | 输入框 placeholder、说明文字优化 |
| 按钮文案 | 按钮文字优化、提示文案调整 |
| 空状态提示 | 列表为空时的引导文案 |
| 错误提示 | 错误信息可读性优化 |
| 布局微调 | 间距、对齐、响应式小问题 |
| 字段说明 | 表单标签、提示文字优化 |

## 本轮不允许修改的范围

| 类型 | 说明 |
|------|------|
| 业务逻辑 | 不修改功能逻辑、数据流、状态管理 |
| 数据库结构 | 不修改表结构、不新增迁移文件 |
| API 接口 | 不修改接口路径、参数、返回格式 |
| 组件架构 | 不重构组件、不引入新组件库 |
| 路由结构 | 不修改路由路径、不新增页面 |
