# 丝网工厂官网与销售系统需求规划文档

## 1. 项目背景

本项目用于帮助一家丝网类生产厂家建设企业官网与销售系统。该网站主要服务于国内外客户，用于展示公司实力、产品信息、工厂照片、证书资料，并支持客户提交询盘、上传需求文件，后续逐步扩展为支持中英文切换、询价车、客户注册、订单管理和在线支付的销售平台。

项目当前不直接建设复杂电商平台，而是优先建设一个可上线、可维护、可扩展的基础系统。

## 2. 项目核心目标

### 2.1 第一阶段核心目标

第一阶段重点解决以下问题：

1. 公司有一个正式、专业、好看的企业官网。
2. 客户能清楚看到公司主营产品、工厂实力、证书资料和联系方式。
3. 客户能查看产品分类、产品详情、规格参数、价格或报价说明。
4. 客户能提交询盘，并上传图纸、规格文件或需求说明。
5. 管理员能在后台自行维护产品、分类、图片、规格、价格和询盘。
6. 网站结构预留中英文切换、询价车、订单、支付和客户注册能力。

### 2.2 后续长期目标

后续逐步扩展为：

1. 中英文双语网站。
2. 国内外客户均可访问和提交需求。
3. 标准产品支持在线下单。
4. 定制产品支持询价报价。
5. 客户可以注册账号并查看历史询盘和订单。
6. 后台可以管理产品、客户、询盘、订单、支付和发货。
7. 网站可用于海外市场推广和搜索引擎获客。

## 3. 项目定位

本项目定位为：

**丝网工厂 B2B 官网 + 产品展示系统 + 后台管理系统 + 询盘系统 + 后续销售交易扩展平台。**

当前不是单纯展示型官网，也不是一开始就做完整网购商城，而是采用渐进式建设路线。

## 4. 业务特点

该公司主要生产和销售丝网类产品，产品特点如下：

1. 产品以标准规格为主，定制规格为辅。
2. 当前可暂按标准品约 70%、定制品约 30% 理解。
3. 标准品可以展示价格，后续可支持在线下单。
4. 定制品需要客户提供材料、尺寸、数量、用途、图纸或特殊要求。
5. 定制品不适合直接付款，适合先提交询盘，由销售人员确认规格和价格后再成交。
6. 国内客户可通过电话、微信、支付宝、微信支付、对公转账等方式沟通和付款。
7. 海外客户可通过邮箱、WhatsApp、PayPal、信用卡或 T/T 电汇等方式沟通和付款。
8. 第一版不强制接支付，先完成产品展示、询盘和后台维护。

## 7. 技术路线建议

### 7.1 推荐路线

当前建议采用：

```text
自写前端展示页面
+
自写或轻量化后台管理系统
+
后端接口服务
+
MySQL 数据库
+
图片/文件上传存储
```

### 7.2 前端技术建议

推荐：

```text
Vue 3 + Vite + Tailwind CSS
```

原因：

1. 开发成本较低。
2. 页面可控。
3. 适合做简洁、好看的企业站。
4. 移动端适配方便。
5. 后续可以扩展后台管理端。

也可以选择：

```text
React / Next.js
```

如果后续重点做海外 SEO，Next.js 更适合。

### 7.3 后台技术建议

推荐两种路线。

#### 路线 A：自写轻量后台

技术组合：

```text
前台：Vue 3 + Vite + Tailwind CSS
后台：Vue 3 + Element Plus
后端：Spring Boot / Node.js / FastAPI
数据库：MySQL
```

优点：

1. 完全可控。
2. 后续扩展订单、支付、客户管理更方便。
3. 不依赖复杂第三方插件。
4. 适合长期维护。

缺点：

1. 开发量较大。
2. 后台登录、权限、文件上传、接口都需要自己做。

#### 路线 B：使用开源后台系统

可选：

```text
Strapi
Directus
WordPress Headless
```

优点：

1. 不需要从零写后台。
2. 能快速管理产品、图片、文章、证书。
3. 上线速度快。

缺点：

1. 后续复杂订单、支付、询价车可能仍需定制。
2. 自定义业务逻辑不如自写后台灵活。

### 7.4 当前更推荐方案

如果希望长期自己掌控项目：

```text
Vue 3 前台
+
Vue 3 后台
+
Spring Boot 或 Node.js 后端
+
MySQL 数据库
```

如果希望尽快上线：

```text
Vue 3 前台
+
Strapi 后台
+
MySQL / PostgreSQL
```
